# MeterX code map

The layout and the rules behind it are in CLAUDE.md ("Architecture"). This file lists every source file.

## Architecture in one screen

```
apps/extension  pages (popup, side panel, settings)  --chrome.runtime messages-->  service worker (background/)
                                                                                    | fetch
apps/site       static pages + the extension pages in demo mode (/app/)             v
services/worker (Cloudflare, default)   services/server (Express, self-host)   same API: /ping /test-file /upload /health /ip
packages/shared  contract, version, quality rules, formatting, share links (pure)
packages/reports PDF, CSV, JSON builders and stats (pure)
```

- Measurement runs in the service worker; the pages only send messages and render.
- Default backend: `WORKER_URL` in `packages/shared`, also in the extension manifest's `host_permissions` and the site's `_headers` CSP.
- Settings live in `chrome.storage.sync` (`serverUrl`, `ispPlan`, `scheduleMinutes`, `notifyOnDrop`); history in `chrome.storage.local` under `history`.

## Message protocol

| Message | Sent by | Handled in | Notes |
|---|---|---|---|
| `startTest` | popup, side panel | `background/index.ts` | Runs `runFullTest`, replies with final status. |
| `cancelTest` | popup | `background/index.ts` | Aborts `testAbortController`. |
| `getServerUrl` / `setServerUrl` | (unused by pages today) | `background/index.ts` | Options page writes storage directly. |
| `rescheduleTests` | options | `background/index.ts` | Re-reads `scheduleMinutes`. |
| `openSidePanel` | nothing | `background/index.ts` | Unreachable, see #72. |
| `testProgress` / `testComplete` / `testError` | background | popup, side panel | Broadcast with `chrome.runtime.sendMessage`. |
