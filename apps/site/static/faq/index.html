Questions, answered

Short answers about MeterX. Anything missing? Ask in the issue tracker.

Is it free?

Yes, with no paid tier, no account and no ads. The code is open source under AGPL-3.0.

Which browsers does it run in?

Firefox, Microsoft Edge and Opera today, and Chrome soon. It also runs in other browsers built on Chromium. Get it for your browser.

What leaves my browser?

Only the test traffic: bytes downloaded from and uploaded to the test server, and the pings. Results are stored in your browser and nowhere else. The privacy page has the details.

Why is my result different from other speed tests?

Each test uses its own servers, number of streams and length. MeterX tests against the nearest Cloudflare location with several streams for a fixed time and trims the slow start. How it measures.

What is bufferbloat?

When a line is busy, routers can queue too much data, so every request waits in line. Speed looks fine but calls and games lag. MeterX measures ping while the line is full and grades the rise from A to F.

Can I use my own test server?

Yes. The repository includes a small server you can run on your own machine or network, and the settings page lets you point MeterX at it.

How do I share a result?

Press Share in the popup. The link carries the result inside it, after the # sign, so it never reaches a server, and this site shows it to whoever opens it.

Where do I report a bug?

In the issue tracker on GitHub.
