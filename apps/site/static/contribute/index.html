From zero to a pull request

  1. Fork and clone

    Fork ajithakdev/meterx, then git clone your fork and run npm install.

  2. Build and load

    npm run build, then load apps/extension/dist/ as an unpacked extension in Chrome, Edge or Firefox.

  3. Change and check

    Make the change on a branch. npm test and npm run lint must pass.

  4. Open a pull request

    Say what changed and why, and link the issue. Small pull requests get reviewed fastest.

The full guide, with the repo layout and every command, is in CONTRIBUTING.md.
